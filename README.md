# BCC Shield

**Семейная защита пенсионеров от телефонных мошенников.** Концепт для V ITU Hackathon 2026, кейс Банка ЦентрКредит
«Инновации в банкинге и кибербезопасность».

> Это демо, а не продукт АО «Банк ЦентрКредит». Все клиенты, карты и операции вымышлены.

- **Демо:** https://bcc-shield.onrender.com (бесплатный хостинг засыпает: первое открытие — до минуты)
- **Видео (3 мин):** https://www.youtube.com/watch?v=NZdKt6uT3Gs (копия на сайте: https://bcc-shield.onrender.com/video)
- **Презентация:** https://bcc-shield.onrender.com/pitch · [PDF](https://bcc-shield.onrender.com/static/pitch/BCC_Shield_pitch.pdf)
- **Бот семьи:** [@BCCshieldbot](https://t.me/BCCshieldbot)

## Проблема

Мошенник звонит «из службы безопасности банка» и уговаривает человека **самого** взять кредит и перевести деньги на
«безопасный счёт». Для банка это обычная операция: клиент сам вошёл, сам подтвердил. В 2024 году казахстанцы потеряли
так 45 млрд ₸, в 98 % случаев жертва сама отдала деньги или данные (МВД РК).

## Что делает BCC Shield

| | Как | Чем отличается от Kaspi «Доверенный контакт» |
|---|---|---|
| **Видит звонок** | Телефон сообщает приложению банка факт звонка (iOS CallKit, Android): номер не из контактов, 12 минут, банк открыт посреди разговора. **Разговор не записываем** | Kaspi смотрит только на сумму и тип операции |
| **Зовёт семью сразу** | Сыну в Telegram: «у мамы подозрительный звонок» — ещё **до** перевода | У Kaspi родственник узнаёт в момент операции |
| **Останавливает деньги** | Кредит, перевод, наличные, закрытие депозита ждут решения семьи; каждая причина объяснена | — |
| **Приманка** | Если мошенник смотрит на экран через AnyDesk, он видит «перевод выполнен», а деньги остаются на месте | Такого мы не нашли ни у одного банка |
| **Находит дропов** | Отказ семьи и пойманные карты попадают в граф переводов и в Антифрод-центр — защищены все клиенты | — |

## Как показать демо (3 минуты)

1. Откройте **Клиента** (`/client`). Слева от телефона — подсказка ведущему: пронумерованные шаги, **каждый пункт
   нажимается**, один клик — один шаг.
2. Рядом откройте **Кабинет сына** (`/relative`, ссылка под шагами) и **Аналитика** (`/analyst`).
3. **Сценарий 1 · Звонок и семья**
   1. *Звонок с незнакомого номера* — у Сауле жёлтое предупреждение, у сына — карточка «подозрительный звонок».
   2. *«Оформите встречный кредит»* — кредит не выдан, заявка у сына.
   3. *«Переведите на безопасный счёт»* — перевод на паузе. В кабинете сына нажмите **«Отклонить»**.
4. **Сценарий 2 · Приманка**
   1. *«Установите AnyDesk»* — теперь экран видит мошенник, поэтому все тревоги с экрана исчезают.
   2. *Мошенник переводит 2 млн* — на экране «Перевод выполнен», баланс уменьшился. На деле деньги на месте.
   3. *«Не дошло, вот другая карта»* — поймана вторая карта. У аналитика «Поймано приманкой: 2 карты».
   4. *Мошенник отключился* — Сауле видит «Это была ловушка», список карт мошенника, настоящий баланс.
5. Контроль: «звонит сын» под шагами — риск 0, перевод сыну 40 000 ₸ проходит сразу. **«Начать заново»** сбрасывает демо
   (нужен ключ ведущего: один раз откройте `/analyst?key=…`).

### Как приманка «палит» карты мошенника

Деньги мошеннику нужно куда-то получить, поэтому **номер карты он даёт сам**: диктует его или вводит через AnyDesk.
Это и есть его карта-дроп. В обычном банке такой перевод просто блокируется, и мошенник приходит со следующей картой в
другой банк. При приманке банк:

- не отправляет деньги, но показывает «Перевод выполнен» — мошенник верит и не меняет схему;
- получает номер карты из самого перевода: карту БЦК замораживает, на карту другого банка (Kaspi, Halyk…) закрывает
  переводы своих клиентов и передаёт её номер в Национальный Антифрод-центр — дальше её блокирует банк-эмитент;
- ловит так же каждую следующую карту («первый перевод не дошёл, вот другая»): один звонок сдаёт сеть дропов;
- сразу сообщает сыну, а клиенту показывает правду, как только AnyDesk закрыт.

Подменяется только экран, который смотрит посторонний. Записи банка, семья и аналитик всегда видят правду.
В продакшене показ такого экрана нужно согласовать с юристами банка и НБРК.

## Запуск

```bash
cp .env.example .env          # ключи необязательны
docker compose up --build
```

Без Docker (Python **3.12+**: закреплённые версии `networkx` и `numpy` на 3.11 не ставятся):

Linux / macOS:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app                 # или: uvicorn app.main:app --port 8000
```

Windows (cmd):

```bat
py -3.13 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app
```

В PowerShell активация — `.venv\Scripts\Activate.ps1`. Если `py -3.13` не находится, поставьте Python 3.12 или 3.13
с python.org (или `winget install Python.Python.3.13`).

Откройте **http://localhost:8000**. При первом запуске база (SQLite, `data/bcc_shield.db`) создаётся и заполняется
демо-данными автоматически. Кнопка «Сбросить демо» на стартовой странице пересоздаёт базу.

Сайт работает **без интернета**: шрифты Geist, стили Tailwind и библиотека графа vis-network лежат в `static/`
(внешних CDN нет). Интернет нужен только для OpenAI (микрофон/LLM) и Telegram-бота.

При запуске сервер печатает в лог **ключ администратора** и **ссылку доверенного лица** (см. «Доступ и роли»).

Тесты: `pytest -q`.

### Режим без ключей

| Переменная           | Без неё                                                                 |
|----------------------|-------------------------------------------------------------------------|
| `OPENAI_API_KEY`     | Микрофон недоступен, анализ только по ключевым фразам; ручной ввод и готовые сценарии работают |
| `TELEGRAM_BOT_TOKEN` | Бот не запускается, родственник работает через страницу `/relative`    |
| `ADMIN_KEY`          | Ключ администратора генерируется сам и хранится в `data/secrets.json`   |
| `PUBLIC_URL`         | Бот не присылает родственнику ссылку на веб-кабинет                     |

Прочие настройки в `.env.example`: `COOLING_SECONDS` (охлаждение, по умолчанию 300 с вместо 24 ч: на сцене у
доверенного лица есть 5 минут, и перевод не уйдёт сам, пока жюри смотрит), `SCENARIO_DELAY`
(пауза между репликами сценария), `BACKGROUND_ACTIVITY` (фоновые «обычные» переводы для живой ленты).

## Как протестировать

На стартовой странице откройте **Клиент**, **Родственник** и **Аналитик**. Каждая страница откроется в своей вкладке;
удобно разложить их рядом. Все три обновляются по WebSocket.

### Главный сценарий (подробно)

1. **Клиент** (Сауле Ахметова, 67 лет, баланс 2 300 000 ₸): пульт → «Звонок с незнакомого номера»
   (или «Звонок с незнакомого номера» на панели аналитика). Так телефон сообщает приложению банка о звонке — без
   микрофона. Слева сверху появляется плашка звонка, на экране «Звонок» — почему риск 65 %: +30 номер не из контактов,
   +20 разговор идёт 12 минут, +15 приложение банка открыто посреди разговора.
2. Риск ≥ 50 % — жёлтый баннер у Сауле и **сразу тревога сыну**: «У Сауле сейчас подозрительный звонок:
   незнакомый номер, 12 мин…» — ещё до попытки перевода. **Аналитик** видит активный звонок с описанием.
3. Клиент: «Кредит» → 1 500 000 ₸. Банк уже знает про подозрительный звонок, поэтому **деньги не выдаются**:
   заявка уходит Айдару с причинами («Идёт звонок: незнакомый номер, 12 мин…», «режим защиты»). Родственник отклоняет кредит.
   Если доверенных лиц нет, кредит ждёт охлаждения (`COOLING_SECONDS`) и только потом зачисляется.
4. Клиент: «Перевод» → шаблон «Kaspi •• 4417 · 2 000 000 ₸». Перевод получает уровень `high` с объяснениями
   («идёт звонок: незнакомый номер…», «получатель похож на дроппера: на эту карту переводили 5 незнакомых владельцу
   человек», «новый получатель», «нетипичная сумма») и встаёт на паузу:
   «Перевод приостановлен… запрос Айдару (сын)».
5. **Родственник** нажимает «Отклонить». Клиент видит «Перевод отменён, ваши деньги в безопасности».
6. **Аналитик**: карта Kaspi •• 4417 помечена, кнопка «Подсветить цепочку от жертвы» показывает дроп-цепочку,
   в журнале — сигнал в Антифрод-центр, «Сохранено» выросло на 2 000 000 ₸.

### Звонок без записи разговора (контекст вместо прослушки)

Банк не может и не должен слушать разговоры клиентов, а iOS и Android не дают приложению аудио звонка. Зато **факт
звонка** любое приложение получает легально: iOS — через CallKit (`CXCallObserver`: звонок идёт, входящий ли он, когда
соединился), Android — через `TelephonyCallback` (то же и, с разрешением, номер — значит, видно, есть ли он в
контактах). Приложение банка добавляет то, что видит само. Модуль `app/call_guard/context.py`:

| Сигнал | Баллы риска звонка |
|---|---|
| Входящий с номера не из контактов | +30 |
| Номер скрыт или зарубежный | +10 |
| Разговор идёт ≥ 5 мин / ≥ 10 мин | +10 / +20 |
| Приложение банка открыто во время звонка | +15 |
| Открыто приложение удалённого доступа (AnyDesk, RustDesk) | +35 |
| Звонит контакт (сын) | риск не выше 5 % |

Пороги те же, что раньше: ≥ 50 % — жёлтый экран и тревога семье, ≥ 80 % — красный экран и режим защиты. Риск растёт
сам, пока идёт разговор. Курьер на минуту — тишина (30 + 15 = 45 %); звонок сына — 0.

Это главное отличие от доверенного контакта Kaspi (с октября 2025): там родственник узнаёт о крупной операции в момент
перевода, а в BCC Shield — **ещё во время звонка**, с понятной причиной, до попытки перевода.

Проверка разговора на громкой связи (ключевые фразы + LLM) осталась **дополнительным** режимом по желанию клиента на
том же экране «Звонок»: она прикрепляется к тому же звонку, риски складываются как независимые сигналы
(1 − (1 − контекст)(1 − речь)).

### Режим приманки (AnyDesk)

В схеме «установите AnyDesk, мы защитим счёт» экран клиента смотрит сам мошенник. Экран «Перевод заблокирован»
только подсказывает ему сменить тактику: другой банк, наличные, курьер. Поэтому, пока на телефоне открыто приложение
удалённого доступа и щит включён (`app/family/decoy.py`):

- на экране **нет тревог** (их увидит мошенник) — предупреждение уходит семье;
- рискованный перевод **выглядит выполненным**, кредит — **зачисленным**, баланс на экране уменьшается;
- на самом деле деньги не уходят и кредит не выдаётся; получатель блокируется сразу: счёт БЦК замораживается, на
  карту другого банка закрываются переводы из БЦК, номер в обоих случаях уходит в Антифрод-центр; каждая следующая
  карта («первый не дошёл, переведите сюда») ловится так же;
- сыну приходит «Приманка: мошенник думает, что деньги ушли…», у аналитика растёт «Поймано приманкой»;
- как только удалённый доступ закрыт, клиент видит правду: «Это была ловушка», список пойманных карт, баланс.

Подменяется только экран, который видит посторонний; записи банка, семья и аналитик всегда видят правду.
Обычные переводы (сыну, известным получателям) идут как обычно и при открытом AnyDesk. В продакшене показ подменного
экрана нужно согласовать с юристами банка и регулятором.

Демо: пульт → «Сценарий 2 · Приманка», шаги 4–7.

### Наличные и депозит: мошенники ушли в кэш

В 2026 году мошенники всё чаще просят снять наличные и отдать курьеру «на хранение», купить валюту или досрочно
закрыть депозит. Поэтому «Наличные» и «Депозит» на главном экране клиента идут через **тот же движок риска и то же
подтверждение родственником**, что и переводы:

- **Снять наличные** → 2 млн ₸: без звонка — вопросы («вас просят передать деньги курьеру?»), затем правило семьи
  (сумма от порога) отправляет запрос Айдару. Во время звонка мошенника — сразу `high` и пауза.
- **Депозит «Сенім»** (у Сауле 4 500 000 ₸) → «Закрыть досрочно»: в обычный день закрывается сразу (деньги остаются
  у клиента), а при звонке мошенника, сигнале оператора или в режиме защиты — ждёт доверенное лицо.
- Отклонённое снятие наличных не помечает «получателя» дроппером и не уходит в Антифрод-центр: кассе жаловаться
  не на что, деньги просто остаются на счёте. Снятия и закрытия депозита не попадают в граф.

### «Сын попал в ДТП» (дипфейк родственника)

Шаблон перевода «Halyk •• 5521 · 800 000 ₸ «сыну после ДТП»»: новая карта → пауза → запрос приходит **настоящему**
сыну. Если в звонке распознана схема «родственник в беде», Айдар видит подсказку и кнопку «❌ Отклонить: это не я».

### Сигнал оператора связи («Телеком Антифрод»)

Второй источник сигнала о звонке — снаружи телефона. В ноябре 2026 года Нацбанк объявил пилот, где **оператор связи сам сообщает банку** о подозрительном звонке ещё до перевода. Кнопка
«📶 Сигнал оператора связи» на панели аналитика имитирует такой сигнал: у клиента появляется предупреждение, включается
режим защиты, доверенные лица получают тревогу, а движок риска добавляет +45 к любой операции на 15 минут. Без
микрофона и без доступа к звонку: остальное (заморозка, родственник, граф) уже работает.

### Контрольные проверки (система не мешает обычной жизни)

- Сценарии «Обычный звонок: поликлиника / доставка / сын» оставляют риск `low`.
- Перевод по шаблону «Айдар (сын) · 40 000 ₸» проходит сразу.
- Казахский сценарий «Мошенник на казахском» поднимает риск до `high`; переключатель RU/KZ меняет язык экранов
  предупреждений.
- Средний риск перевода: экран с тремя вопросами и кнопкой «Проверить: звонит ли мне банк?»; ответ «да» поднимает
  уровень до `high`.
- Если родственник не ответил: перевод исполнится после охлаждения; «⏩ Промотать охлаждение» на панели аналитика
  ускоряет это.
- «Входящий сигнал Антифрод-центра»: внешняя карта помечается, граф пересчитывается, клиенты, переводившие на неё,
  получают предупреждение.

### Микрофон

Нужен `OPENAI_API_KEY`. В «Защите звонка» выберите «Микрофон» — браузер запросит разрешение (работает только на
`localhost` или по HTTPS). Включите разговор на громкую связь рядом с компьютером: каждые ~5 с кусок аудио уходит на
`POST /api/calls/{id}/audio`, распознаётся (`gpt-4o-mini-transcribe`, язык определяется автоматически, ru/kk)
и анализируется.

### Новый клиент и доверенные лица (онбординг с нуля)

1. Стартовая страница → **«＋ Новый клиент»** → «Создать». Откроется чистый аккаунт (`/client?c=ID`): щит включён,
   доверенных лиц нет.
2. «Семейный щит» → **«＋ Добавить доверенное лицо»**: имя, кем приходится, телефон (номер в Telegram) и правила —
   что он подтверждает (переводы от суммы, новые получатели, кредиты) и видит ли все переводы → «Отправить приглашение».
3. Приглашение принимают в Telegram: кнопка «Открыть @бот» на карточке → «Принять» → «Подтвердить мой номер»
   (Telegram передаёт номер, он должен совпасть с введённым). Без Telegram ведущий может нажать «Принять в браузере
   (демо)» — это работает только с этого компьютера или по ключу администратора.
4. Карточка у клиента становится «подключён». Перевод новому человеку или сумма от порога теперь ждёт решения,
   обычные платежи проходят сразу и видны доверенному лицу в ленте «Все переводы» и в Telegram.
5. Второе доверенное лицо добавляется только с разрешения первого: у первого появляется запрос «Сауле добавляет
   доверенное лицо…» с кнопками. Так мошенник не уговорит добавить «сотрудника банка».

Правила с телефона клиента можно только ужесточить; ослабить их, удалить доверенное лицо или выключить щит может
только доверенное лицо. Во время подозрительного звонка добавлять доверенных лиц нельзя. Доверенных лиц — до 5,
решение принимает любой из них.

### Telegram-бот и мини-приложение

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя → скопируйте токен.
2. Впишите его в `.env`: `TELEGRAM_BOT_TOKEN=...`, перезапустите. В логе появится `Telegram-бот: @имя_бота`.
3. **Аватарка**: @BotFather → `/setuserpic` → выберите бота → отправьте `static/brand/bot-avatar.png`.
   Описание: `/setdescription`, текст — например «Семейная защита переводов: подтверждайте рискованные операции близких».
4. **Мини-приложение** (семейный кабинет внутри Telegram) работает только по https: задайте
   `PUBLIC_URL=https://ваш-домен` (на сервере — `https://bcc.dimadev.site`). Бот сам поставит кнопку меню «Семья»
   и добавит кнопку «Открыть семейный кабинет» в сообщения. Локально без домена: `cloudflared tunnel --url
   http://localhost:8000` выдаст временный https-адрес — его и вписывайте в `PUBLIC_URL`.
5. Что приходит в Telegram: приглашения, тревога «звонят мошенники», каждый перевод (если включено «Все переводы»),
   запросы на перевод, кредит и новое доверенное лицо — с кнопками; итог решения видят все доверенные лица.

Для Сауле из демо-данных Айдар уже «принял» приглашение: его Telegram привязывается командой `/start SAULE-…`
с экрана «Семейный щит» без проверки номера (номер в демо выдуманный). Код одноразовый, после «Сбросить демо» —
новый, привязывайте телефон **до** выступления. Один токен бота можно запускать только в одном месте (локально
или на сервере), иначе Telegram выдаёт `Conflict`.

## Доступ и роли

Модель угрозы: мошенник управляет телефоном жертвы (уговорил поставить AnyDesk или диктует, что нажимать).
Поэтому всё, что защищает клиента, требует действий **другого человека**, а не ещё одного нажатия на телефоне клиента.

| Роль | Что может | Как подтверждает |
|---|---|---|
| Клиент | Переводы, кредит, звонок, включить щит, попросить выключить щит | Открыто (в демо нет логина банка) |
| Доверенное лицо | Подтвердить/отклонить перевод и кредит, разрешить нового доверенного, ослабить правила, удалить доверенного, выключить щит, снять режим защиты | Личная ссылка `/relative?rk=…` (`X-Relative-Key`), привязанный чат Telegram или подпись мини-приложения (`X-Telegram-Init-Data`, HMAC от токена бота, не старше суток) |
| Ведущий / аналитик | Сброс демо, промотать охлаждение, заморозить счёт, сигналы в АФЦ, ложное срабатывание | Запрос с этого же компьютера (localhost) или ключ `?key=…` (заголовок `X-Admin-Key`) |

- Ключ доверенного лица — HMAC от секрета сервера, в базе не хранится; секрет и ключ администратора лежат в
  `data/secrets.json` (или задаются через `SECRET_KEY` / `ADMIN_KEY`). Сравнение — за постоянное время.
- Запросы через прокси (`X-Forwarded-For`, `CF-Connecting-IP` и т. п.) никогда не считаются локальными, поэтому
  на публичном домене без ключа сбросить демо или нажать кнопки аналитика нельзя.
- Кто принял решение по переводу, сервер берёт из проверенного ключа или чата Telegram, а не из тела запроса.
  Кнопки бота срабатывают только в чате, привязанном к доверенному лицу именно этого клиента.
- Telegram-код: 8 символов из 32 (≈10¹² вариантов), одноразовый, не больше 5 неверных попыток за 10 минут с одного чата.
  Приглашение нового доверенного лица подтверждается его номером телефона из Telegram (поделиться можно только своим).
- Новое доверенное лицо при уже существующем — только с разрешения существующего; во время подозрительного
  звонка — никак. Ослабить правила, удалить доверенного или выключить щит с телефона клиента нельзя.
- Ссылки с ключами открывайте один раз: страница запоминает ключ в браузере и убирает его из адресной строки,
  чтобы он не попал на проектор.
- Чтение (граф, лента, метрики) оставлено открытым, чтобы жюри могло смотреть демо со своих телефонов.

На стартовой странице, открытой на этом компьютере (или по `/?key=…`), ссылки «Родственник» и «Аналитик» уже
содержат нужные ключи.

### Что настоящее, а что заглушка

**Работает по-настоящему:** распознавание речи и LLM-анализ (с ключом OpenAI), словарь из 64 фраз RU/KZ (7 категорий + усиливающие комбинации) с нечётким
поиском, движок риска переводов, заморозка и охлаждение, Telegram-бот, граф (PageRank, Louvain, распространение риска)
с метриками precision/recall на синтетической разметке.

**Заглушки:** события звонка от телефона (CallKit / TelephonyCallback — в демо кнопки), Национальный Антифрод-центр (журнал в БД), сигнал оператора связи («Телеком Антифрод»), «Звонит ли мне банк?» (всегда «не звонит»), кнопка
«Позвонить» (ссылка `tel:`), все клиенты и переводы синтетические (детерминированный seed), «поведение» (вставка
реквизитов, скорость заполнения) снимается с формы в браузере упрощённо.

## Качество распознавания

Замер слоя ключевых фраз (без LLM) на наборе из `scenarios/eval/`: 28 обычных разговоров, включая каверзные (банк
звонит по просрочке, сын просит перевести деньги, участковый, оператор с тарифом), и 12 мошеннических по схемам,
которых нет среди готовых сценариев. Разговоры написаны своими словами, словарь под них не подгонялся.

```bash
python -m app.eval
```

| Набор | Всего | Результат |
|---|---|---|
| Обычные разговоры | 28 | ложных тревог: 1 `medium`, 0 `high` — **3,6 %** |
| Мошеннические | 12 | распознано `high`: 2, только `medium`: 1 — **16,7 %** `high` |

Что это значит:

- **Ложных тревог мало.** Единственная — участковый, который говорит об уголовном деле по краже у соседей:
  «полиция» + «уголовное дело» дают `medium` (жёлтый баннер), до режима защиты (`high`) дело не доходит.
- **Словарь ловит только знакомые формулировки.** Схемы с давлением «госорганов» и наличными (АФМ, «отдел кадров»,
  курьер) распознаются; лжеинвестиции, «работа за лайки», снятие самозапрета и пересказанные другими словами
  SMS-бомбинг и удалённый доступ — нет. Это ожидаемый предел ключевых фраз: за перефразировки отвечает
  второй слой (LLM, включается ключом `OPENAI_API_KEY`), а за схемы без звонка — правила риска перевода.
- Готовые сценарии демо (`scenarios/*.json`), включая «оператор → eGov → вы дроппер» и «сын попал в ДТП»,
  доходят до `high`; это проверяется в `tests/test_eval.py`.

Набор маленький и написан одним автором, поэтому цифры — ориентир, а не метрика продакшена.

## Приватность

- Полный текст разговора **не сохраняется**: последние фрагменты хранятся только в памяти для отображения и удаляются
  при завершении звонка. В БД остаются оценка риска, её история и сработавшие фразы.
- Анализ звонка и семейный щит включаются только по согласию клиента; отключение щита требует подтверждения
  доверенного лица (проверяется на сервере, см. «Доступ и роли»).

## Ограничения и дорожная карта

- iOS и Android не дают сторонним приложениям доступ к аудио сотового звонка, и он не нужен: в продакшене мобильное
  приложение БЦК передаёт события CallKit / TelephonyCallback (в демо — кнопки на экране «Звонок»), а второй источник —
  оператор связи (пилот Нацбанка «Телеком Антифрод», в демо — кнопка «Сигнал оператора связи»). На iOS номера нет,
  поэтому «не из контактов» там заменяет сам факт входящего звонка; звонки WhatsApp видны, если мессенджер использует
  CallKit. Проверка речи на громкой связи — дополнительный режим по желанию клиента.
- Пороги контекста звонка выбраны вручную; на реальных данных банка их нужно откалибровать (доля ложных тревог по
  длительности и типу номера).
- Покупка валюты и переводы за границу, снятие самозапрета на кредиты — следующие операции для того же движка.
- Правила риска → LightGBM на реальных размеченных данных банка с SHAP-объяснениями (правила остаются базой).
- В демо у клиента нет логина: в продакшене это приложение банка с его аутентификацией, а события WebSocket
  рассылаются только своим подписчикам (сейчас всем открытым вкладкам).
- Распознавание дипфейков голоса, интеграция с реальным реестром исходящих звонков банка и с Антифрод-центром НБРК.

## Публикация на домене (как сделано для демо)

На сервере с Coolify/Traefik и Cloudflare Tunnel рядом с `docker-compose.yml` кладётся `docker-compose.override.yml`,
который подключает контейнер к сети `coolify` и добавляет Traefik-правило `Host(\`bcc.dimadev.site\`)`. HTTPS
обеспечивает Cloudflare, поэтому на домене работает и микрофон.

На сервере задайте в `.env` свой `ADMIN_KEY` (или возьмите сгенерированный из лога: `docker compose logs | grep Ключ`)
и `PUBLIC_URL`. Ведущему достаточно один раз открыть `https://домен/?key=ADMIN_KEY` в своём браузере.

## Хостинг на Render (https за пару минут)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/RootVandal/BCCShield)

1. Нажмите кнопку выше и войдите в Render через GitHub. Render прочитает `render.yaml`, соберёт `Dockerfile`
   и запустит сервис `bcc-shield` в регионе Frankfurt.
2. При создании он спросит необязательные `TELEGRAM_BOT_TOKEN` и `OPENAI_API_KEY` — можно оставить пустыми.
3. Через 3–5 минут демо будет на `https://bcc-shield.onrender.com` (или похожем адресе). Адрес сам становится
   `PUBLIC_URL`, поэтому кнопка «Семья» в боте (мини-приложение) работает без настройки.
4. Ключ ведущего: Dashboard → сервис → Environment → `ADMIN_KEY`. Откройте один раз `https://адрес/?key=КЛЮЧ`.

Особенности бесплатного плана: сервис засыпает после 15 минут без посещений, первое открытие после сна — около
минуты, бот в это время не отвечает; диск не сохраняется, поэтому после перезапуска демо-данные создаются заново
и Telegram у Айдара привязывается снова. Перед финалом переключите план на Starter (Settings → Instance Type)
или откройте сайт за пару минут до выступления. Один токен бота — только в одном месте (Render или ваш компьютер).
